# User Access

## Access principle

Anyone authorized to view the tool may perform all supported maintenance activities.

## Permissions (this release)

| Capability | Allowed for viewers |
|------------|---------------------|
| View the employee list | Yes |
| Select an employee record | Yes |
| Create an employee | Yes |
| Edit an employee | Yes |
| Activate an employee | Yes |
| Deactivate an employee | Yes |

## Out of access scope for this release

- Separate roles with different permission levels (for example, view-only vs. edit)
- Approval workflows before activate or deactivate
- Restrictions that limit some viewers to a subset of operations
